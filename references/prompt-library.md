# AI 生成提示词库

按画面/视频/音频三类组织。方括号 `[ ]` 为需要替换的变量；先定好统一风格前缀，保证全片一致。生成后若用于商业发布，避免出现真实品牌 Logo、真实人物与可识别商标。

## 目录

1. 统一风格设定
2. 图片生成提示词
3. 视频生成提示词
4. 音频生成提示词
5. 使用与迭代规则

## 1. 统一风格设定

### 风格前缀（所有画面共用，按需追加）

```
夜间电脑屏幕录屏质感，暗色 UI，冷蓝色调，低饱和，轻微暗角与噪点，
系统默认无衬线字体，界面元素对齐规整，真实软件截图风格，16:9 高清
```

### 手机界面变体

```
智能手机竖屏界面，夜间模式，冷蓝暗色 UI，状态栏显示时间与电量，
真实 App 截图质感，9:16 高清
```

### 通用负面约束

```
不要真人出镜，不要血腥内脏，不要真实品牌 Logo，不要水印，不要乱码文字，
不要多余手指/畸形，不要过曝，不要卡通化，不要 AI 生成痕迹
```

注意：画面中的文字尽量在生成后用剪辑软件叠加，AI 直接生成大段中文容易出错；生成时只要求预留文字区域。

## 3. 视频生成提示词

动态优先在剪辑里做关键帧（消息逐条进入、弹窗、鼠标移动）；需要真实运镜或画面变化时再用视频生成。

### 3.1 静态界面的“操作感”

```
一段电脑屏幕录制，鼠标指针缓慢移动到聊天窗口，单击打开，
新消息逐条从底部滑入并伴随轻微高亮，窗口有自然的拖动抖动，
冷蓝暗色 UI，固定机位，时长 5 秒，真实操作节奏
```

### 3.2 监控画面动态

```
固定监控视角，夜视噪点画面，空走廊中一个人形剪影缓慢从画面边缘出现并停住，
动作僵硬、不自然，时间码持续走动，信号轻微闪烁，氛围诡异，时长 8 秒
```

### 3.3 界面故障/花屏

```
屏幕画面突然卡顿、撕裂、出现彩色噪点条与闪帧，瞬间恢复正常，
故障持续约 1 秒，模拟信号干扰，冷蓝色调，快速剪辑感
```

### 3.4 消息连续弹出（紧张段）

```
屏幕上聊天消息快速连续弹出，提示音节奏越来越密，多个红色警报弹窗叠加，
鼠标慌乱移动却点不中关闭按钮，画面轻微晃动，紧张感持续升级，时长 10 秒
```

## 4. 音频生成提示词

### 4.1 低频音床

```
持续的低频嗡鸣与极轻的环境底噪，音量平稳偏低，阴暗压抑，
无明显旋律，可循环，时长 30 秒，适合作为恐怖视频背景音床
```

### 4.2 紧张段音床

```
低频嗡鸣逐渐增强，加入不规则的心跳般脉冲与轻微金属共振，
紧张不安，能量缓慢爬升，时长 15 秒
```

### 4.3 消息提示音

```
一声短促清脆的软件消息提示音，“叮”，干净无杂音，时长 0.5 秒，
现代即时通讯 App 风格
```

### 4.4 鼠标与键盘

```
鼠标单击声、快速键盘敲击声，近距离收音，真实办公环境，时长 3 秒
```

### 4.5 敲门声（突发惊吓）

```
三声沉重有力的敲门声，木质门板共振，近距离，声音突然且响亮，
随后一秒完全安静，时长 3 秒
```

### 4.6 警报声

```
电子安防警报，急促重复的蜂鸣，红色警报感，尖锐但不刺耳，时长 5 秒
```

### 4.7 低频冲击（高潮）

```
一次低沉的次声波冲击，伴随瞬间的能量爆发与尾音震动，
用于惊吓点，时长 2 秒，动态强烈
```

## 5. 使用与迭代规则

- 先出 1 张关键界面确认风格，再批量生成其余画面，避免风格跑偏后返工。
- 固定并记录随机种子、模型版本与风格前缀，保证续集可复用同一视觉系统。
- 文字一律后期叠加；生成图只负责底图与版式。
- 每个突发声先在时间轴上标注，再单独生成、手动对位，控制全片惊吓点数量。
- 成片检查：音床是否全程覆盖、提示音是否与动作对位、低频是否在高潮处明显增强。
