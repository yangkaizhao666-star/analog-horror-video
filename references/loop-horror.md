# 循环类恐怖创作方法（时间循环 / 死亡轮回）

本文件是屏幕录屏式模拟恐怖在“时间循环”子类型下的专项方法。它用 doubao-creative-drama 的剧作框架（故事脊柱、信息差账本、恐怖类型承诺）约束循环故事，专治“规则临时变化、因果像流水账、反转靠口述”。

## 1. 类型承诺

循环恐怖的核心情绪不是“吓一跳”，而是“全知却无法改变”的绝望，以及“规则之下，谁在被审判”的悬念。观众的满足感来自：规则稳定可学、线索公平可推、结局由主角此前的选择造成。

失败信号：规则随剧情需要临时增减；每轮只是换个死法却没有新信息；结局靠巧合、新设定或外援打破。

## 2. 统一规则（全剧固定，不临时改变）

动笔前先定死四条铁律，写进故事圣经，全剧不违反：

1. **循环周期 = 一天**：每次循环从早晨（固定起床时间）开始，到晚上的死亡时刻见分晓。一天内可自由调查、移动、收集物证。
2. **死亡线（晚上）**：死亡时刻就是过去死亡事件的真实时刻（如 23:47），若在当天没有解决制造者，到此即被杀死，随后重置回当天早晨。
3. **记忆**：明确谁保留记忆。推荐“全员记忆”，把孤独预知升级为群体心理恐怖与人性博弈。
4. **命数显示**：仅在每天早晨开局时变化，白天设备正常使用、正常充电。

## 3. 命数机制：用日常设备的异常暗示，不点破

推荐用手机电量作为“还剩几轮”的隐藏倒计时，原则是“日常中的异常”，而非夸张的故障：

- 手机在一天内**正常使用、正常耗电、正常充电**，不做“无法充电”“屏幕碎裂”这类突兀设定。
- 唯一异常：每天早晨醒来时，**开局电量基准**比上一天早晨低固定值（如每次 -25），即便白天充过电也一样。
- 节点示例：100 → 75 → 50 → 25 → 0；归零即被永远留在循环里。
- 角色**不点破、不解释**这个规律，只让电量数字在聊天界面、锁屏里自然出现，让观众自己发现并产生“命在变少”的焦虑。

## 4. 因果链：让“过去的事件”与“现在的循环”闭环

循环故事最容易松散，必须用一条因果链把过去和现在焊死：

1. **过去事件**：发生过一桩“未被公正审判”的事（如受害者先杀仇人，相关者随后接连死亡，形成一份被逐一划掉的名单），制造者在锚点时刻死亡，带着执念成为空间规则。
2. **制造者为何无法自行了结**：它自身也是有罪者，无法自我审判，因此需要一个“能看见规则的局外人”替它完成结案，或接替它。
3. **现在的触发**：主角因一个具体动作（发现当年物证）触发沉睡规则，触发时在场者被卷入——这解释了“为什么是他们、为什么是现在”。
4. **关键变量**：安排一个角色与过去事件有血缘/因果联系，让两条时间线交叠，也埋下猜忌。
5. **一天内的节奏分配**：早晨重置、确认记忆与当日目标；白天利用课堂、图书馆、档案馆、辅导员、旧住址等场景调查取证；傍晚危险信号开始出现；晚上进入死亡时刻，没解决即被杀死。把信息释放和场景切换压进这条时间线，避免静态对话堆积。

## 5. 信息差与公平线索账本

反转必须是对已有线索的“重新解释”，不是临时添加新事实。按轮次自然释放线索，每条线索都在正常场景里承担当前功能：

- 第 1 天：一个名字、一件物证、知情者的失态。
- 第 2 天：旧新闻/删帖快照，确认“这里死过人”，但不给全貌。
- 第 3 天：完整名单、被划掉脸的合影，复原过去事件轮廓；关键角色身份揭晓。
- 第 4 天：名单的最后一环指向主角自身，理解规则真相，直面制造者。

登记每条信息：观众何时知道、主角何时知道、公平线索在哪、错误解释是什么、在哪个位置揭示、揭示后产生什么后果。

## 6. 多视角与全员记忆

- 全员记忆后，多视角切换天然成立：可分别进入不同角色的手机屏幕，看到各自的记录与同一个命数数字。
- 外围角色（辅导员、班级群、同学、球友）在每轮被重置、不知情，其“正常”反衬循环内的异常；他们的发言必须符合自身立场——管理者维稳怕担责、群像起哄或恐慌、朋友讲义气行动派。
- 让外围者因“进入影响范围”而被卷入，是扩展张力的有效装置（朋友来帮忙，结果也被困）。

## 7. 结局两种范式（由主题统摄）

主题示例：私刑审判、以恶制恶是否等于正义。

- **黑暗闭环**：主角认同制造者的逻辑，接替它成为新的规则执行者，名字刻入空间，循环重启，等待下一个闯入者——轮回闭环，恐怖余味最长。
- **了结解脱**：主角发现复仇越界或真相另有隐情，选择不延续仇恨、把证据交给现实审判，执念消散，时间终于走到锚点之后。可留一个小异常做续集钩子。

## 8. 自检清单

- 四条规则是否全剧稳定、无临时变化？
- 锚点时间是否与过去死亡事件的真实时刻一致？
- 命数机制是否“日常化、不点破”，让观众自己发现？
- “为什么是他们、为什么是现在”是否有明确因果，而非巧合？
- 结局是否由主角此前选择造成，没有靠新设定或外援？
- 每条反转是否能由已出现的公平线索复盘？
- 外围角色发言是否符合各自立场，是否与循环内成员形成对照？
